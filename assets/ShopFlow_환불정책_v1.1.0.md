# ShopFlow 환불 정책 안내 (v1.1.0)

> 데모용 가상 문서입니다. ShopFlow 는 가상의 쇼핑몰 서비스입니다.

## 1. 접수 기간
- 일반 회원: 구매일부터 30일 이내에 접수할 수 있습니다.
- VIP 회원: 구매일부터 60일 이내에 접수할 수 있습니다.
- 기간이 지난 주문은 접수할 수 없습니다.

## 2. 환불 사유
- 환불을 접수할 때 사유를 입력해야 합니다 (1~200자).
- 구버전 모바일 앱(3.1~3.3)은 2026-12-01까지 사유 없이도 접수할 수 있습니다.
- 2026-12-02부터는 구버전 앱에서 접수할 수 없으며, 웹에서 접수해 주세요.

## 3. 고액 환불 승인
- 환불 금액이 1,000,000원을 초과하면 관리자 승인 후에 처리됩니다.
- 승인 전에는 환불 처리와 승인 안내 이메일이 발송되지 않습니다.
- 정확히 1,000,000원인 경우, 배송 중이 아니면 자동으로 승인됩니다.
- 배송 중인 주문은 금액과 관계없이 관리자 승인이 필요합니다.

## 4. 접수되지 않는 경우
- 취소된 주문
- 접수 기간이 지난 주문
- 남은 환불 가능 금액을 초과하는 요청 (부분 환불은 남은 금액 한도 안에서 가능합니다)
